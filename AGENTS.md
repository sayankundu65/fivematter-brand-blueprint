# FiveMatter Brand Blueprint Guidelines

## Overview

This repository contains the official brand foundation, design system, and digital brand guidelines for **FiveMatter** (_Focus. Solve. Scale._).

## Brand Identity Dimensions

- **People**: The roles, skills, and behaviours that make change real.
- **Process**: The repeatable flows that turn intent into delivery.
- **Data**: The evidence that sharpens decisions and measures progress.
- **Technology**: The platforms and tools that enable the operating model.
- **Governance**: The ownership and controls that keep change on course.

## Architecture

- Built with **React 19**, **TanStack Router / TanStack Start**, **Vite**, and **Tailwind CSS**.
- Production builds output both client assets with static export (`.output/public`) and Cloudflare SSR support (`.output/server`).
